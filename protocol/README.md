# Protocol Explorer — 복원 소스

원작 및 디자인: **Dilum Sanjaya**  
원본 사이트: https://protocol-explorer-alpha.vercel.app/

배포본의 동작을 보존하면서 개발·유지보수할 수 있게 재구성한 JavaScript 프로젝트입니다. 수업별 모듈, 의미 있는 함수·지역 변수 이름, 읽기 쉬운 제어 흐름, 핵심 알고리즘 설명과 회귀 검사를 갖추었습니다. 프레임워크 없이 DOM·SVG·Web Animations API를 사용하고, Vite로 개발·빌드합니다.

제작자가 공개한 원본 저장소에서 받은 소스는 아닙니다. 원래 파일 구조·변수명·주석·개발 테스트는 배포본에 남아 있지 않습니다. 현재 이름과 설명은 실제 동작을 분석해 작성했으며, 원본과의 일치는 보존된 콘텐츠와 검증한 실행 결과를 기준으로 합니다.

## 실행

Node.js 22.12 이상이 필요합니다.

```powershell
npm.cmd install
npm.cmd run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 여세요. 수정한 파일은 개발 서버에 바로 반영됩니다.

```powershell
npm.cmd run build
npm.cmd run preview
```

빌드 결과는 `dist/`에 생성됩니다. 한국어는 오른쪽 위 언어 메뉴에서 선택합니다.

```powershell
npm.cmd test
```

Node 내장 테스트 러너를 사용합니다. 14개 수업의 내용, 215개 패킷의 바이트·필드, 시퀀스 배치가 변경 전 기준값과 일치하는지 확인하고, 재생 취소·초기화·속도·일시정지를 검사합니다. `test/fixtures/distribution-baseline.json`은 변경 전 데이터를 요약한 해시입니다. 단순히 테스트를 통과시키기 위해 이 기준값을 다시 생성하지 마세요.

## 동작 흐름

`main.js`가 언어를 복원하고 화면을 구성합니다. 선택된 수업의 `steps[].events`를 `createLessonPlayer()`가 순서대로 실행하며, 하나의 재생 상태를 사이드바·설명·패킷 표·시퀀스 보기로 전달합니다. `clock.js`는 모든 애니메이션의 속도와 일시정지를 맞춥니다. 수업 변경·초기화 시 취소 토큰을 바꿔 이전 애니메이션이 현재 상태를 덮어쓰지 않게 합니다.

패킷 검사는 수업 이벤트를 `encode.js`에서 바이트·필드·계층으로 변환합니다. 암호화·난수·생략된 파일 데이터처럼 알 수 없는 바이트는 `null`이며 화면에 `··`로 표시됩니다. 시퀀스 보기는 `timeline.js`의 송수신 시각과 노드별 지연을 사용합니다. 번역은 영어 원문을 키로 찾고, 동적인 숫자 문장은 언어별 정규식으로 처리합니다.

이 프로젝트는 실제 통신을 캡처하지 않고, 내장된 교육용 패킷 시나리오를 재생합니다. 기존 배포본의 고정 CSP 메타 태그는 Vite 개발 서버의 모듈 갱신을 위해 제거했습니다.
