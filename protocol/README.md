# Protocol Explorer — 복원 소스

원작 및 디자인: **Dilum Sanjaya**  
원본 사이트: https://protocol-explorer-alpha.vercel.app/

배포본의 동작을 보존하면서 개발·유지보수할 수 있게 재구성한 JavaScript 프로젝트입니다. 수업별 모듈, 의미 있는 함수·지역 변수 이름, 읽기 쉬운 제어 흐름, 핵심 알고리즘 설명과 회귀 검사를 갖추었습니다. 프레임워크 없이 DOM·SVG·Web Animations API를 사용하고, Vite로 개발·빌드합니다.

제작자가 공개한 원본 저장소에서 받은 소스는 아닙니다. 원래 파일 구조·변수명·주석·개발 테스트는 배포본에 남아 있지 않습니다. 현재 이름과 설명은 실제 동작을 분석해 작성했으며, 원본과의 일치는 보존된 콘텐츠와 검증한 실행 결과를 기준으로 합니다.

## 실행

Node.js 22.12 이상이 필요합니다.

```powershell
npm.cmd install
npm.cmd run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 여세요. 수정한 파일은 개발 서버에 바로 반영됩니다.

```powershell
npm.cmd run build
npm.cmd run preview
```

빌드 결과는 `dist/`에 생성됩니다. 화면은 한국어로 고정되어 있으며 언어 선택 메뉴는 없습니다.

```powershell
npm.cmd test
```

Node 내장 테스트 러너를 사용합니다. 14개 수업의 내용, 215개 패킷의 바이트·필드, 시퀀스 배치가 변경 전 기준값과 일치하는지 확인하고, 재생 취소·초기화·속도·일시정지를 검사합니다. `test/fixtures/distribution-baseline.json`은 변경 전 데이터를 요약한 해시입니다. 단순히 테스트를 통과시키기 위해 이 기준값을 다시 생성하지 마세요.

## 동작 흐름

`main.js`가 한국어 화면을 구성합니다. 선택된 수업의 `steps[].events`를 `createLessonPlayer()`가 순서대로 실행하며, 하나의 재생 상태를 사이드바·설명·패킷 표·시퀀스 보기로 전달합니다. `clock.js`는 모든 애니메이션의 속도와 일시정지를 맞춥니다. 수업 변경·초기화 시 취소 토큰을 바꿔 이전 애니메이션이 현재 상태를 덮어쓰지 않게 합니다.

패킷 검사는 수업 이벤트를 `encode.js`에서 바이트·필드·계층으로 변환합니다. 암호화·난수·생략된 파일 데이터처럼 알 수 없는 바이트는 `null`이며 화면에 `··`로 표시됩니다. 시퀀스 보기는 `timeline.js`의 송수신 시각과 노드별 지연을 사용합니다. 영어 원문 키를 한국어 사전에서 찾고, 동적인 숫자 문장은 한국어 번역 정규식으로 처리합니다.

이 프로젝트는 실제 통신을 캡처하지 않고, 내장된 교육용 패킷 시나리오를 재생합니다. 기존 배포본의 고정 CSP 메타 태그는 Vite 개발 서버의 모듈 갱신을 위해 제거했습니다.

## 확인된 상태

현재 UI와 아이소메트릭 장치는 [neobrutal-ui의 기본 Mono 팔레트](https://github.com/andongmin94/neobrutal-ui/blob/main/registry/src/data/colors.ts)를 기준으로 합니다. 밝은 배경 `#f4f5f7`과 차콜 `#27282b`, 다크 배경 `#18191c`과 밝은 주색 `#e4e7ec`을 사용하며, 순검정 대신 차콜 윤곽·단색 그림자를 적용했습니다. UI와 장치의 라임·올리브색은 제거했습니다. 학습 상태는 체크·번호·빈 틀·부분 채움으로 구별하고, 패킷 배지·화살표·계층별 의미 색은 유지합니다.

한국어만 제공하며 다른 언어 사전·선택 메뉴와 화면의 제작자 크레딧은 제거했습니다. 이전 언어 설정과 무관하게 한국어로 표시합니다. 원작자 정보는 이 문서에 보존합니다. 원본 도형·배치·카메라·패킷 애니메이션·레슨 내용은 유지하며, 테마·재생·패킷 검사·시퀀스·모바일 메뉴를 확인했습니다. Pretendard는 `public/fonts/`에 포함했으며 함께 있는 라이선스를 따릅니다.
