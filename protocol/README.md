# Protocol Explorer — 복원 소스

원작 및 디자인: **Dilum Sanjaya**  
원본 사이트: https://protocol-explorer-alpha.vercel.app/

현재 로컬 배포본의 JavaScript와 CSS를 편집·재빌드할 수 있도록 정리한 프로젝트입니다. 제작자가 공개한 원본 저장소에서 받은 소스는 아닙니다. 빌드 과정에서 사라진 주석, 원래 파일 구조, 원래 변수명은 복구할 수 없으며, 이 프로젝트의 파일 분리와 주요 식별자 이름은 기능을 분석해 붙였습니다. 함수 내부의 짧은 지역 변수명은 일부 남아 있습니다.

## 실행

Node.js 22.12 이상이 필요합니다.

```powershell
npm.cmd install
npm.cmd run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 여세요. 수정한 파일은 개발 서버에 바로 반영됩니다.

```powershell
npm.cmd run build
npm.cmd run preview
```

빌드 결과는 `dist/`에 생성됩니다. 한국어는 오른쪽 위 언어 메뉴에서 선택합니다.

## 수정 위치

| 경로 | 역할 |
| --- | --- |
| `src/main.js` | 앱 초기화, 화면 연결, 사용자 조작 |
| `src/lessons/*.js` | 14개 프로토콜별 수업, 설명, 패킷 시나리오 |
| `src/lessons/helpers.js` | 패킷 이벤트와 핸드셰이크 생성 공통 함수 |
| `src/lessons/index.js` | 수업 목록과 프로토콜 분류 |
| `src/ui/` | 헤더, 사이드바, 시퀀스 보기, 패킷 검사기, 설명 패널 |
| `src/simulation/` | 네트워크 그림, 애니메이션, 재생 시계와 플레이어 |
| `src/packets/encode.js` | 패킷 바이트와 필드 정보 생성 |
| `src/locales/ko.js` | 한국어 번역 |
| `src/i18n.js` | 언어 선택과 번역 처리 |
| `src/progress.js` | 브라우저 학습 진도 저장 |
| `src/styles.css` | 스타일 |
| `public/` | 아이콘, 웹폰트 등 정적 파일 |

이 프로젝트는 실제 통신을 캡처하지 않고, 내장된 교육용 패킷 시나리오를 재생합니다. 기존 배포본의 고정 CSP 메타 태그는 Vite 개발 서버의 모듈 갱신을 위해 제거했습니다.
