# 탐색기 모음

프로토콜, CPU 스케줄링, 메모리, 트랜잭션, 디스크 스케줄링, Git 탐색기를 한 주소에서 엽니다. 화면 왼쪽 위의 탐색기 이름으로 주제를 바꿀 수 있습니다.

이 폴더를 여섯 탐색기 프로젝트와 같은 디렉터리에 두고 실행합니다.

```sh
npm ci
npm start
```

<http://127.0.0.1:5173/>에서 시작합니다. `/memory/`, `/git/`처럼 특정 주제로 바로 들어갈 수 있고, 트랜잭션의 교착 상태 시나리오는 `/transaction/deadlock.html`에 있습니다.

탐색기 소스를 수정한 뒤 `npm run build`를 실행하면 통합본에 반영됩니다. `dist/`를 웹 서버의 루트에 올리거나 `npm run preview`로 빌드 결과를 열 수 있습니다. 주제 이름, 경로, 소스 폴더는 `public/explorers.js`에 있습니다.
