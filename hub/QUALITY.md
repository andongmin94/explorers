# 해설을 가리고 확인한 여섯 탐색기

2026년 11월 11일 통합본에서 이전 검수의 여섯 장면과 POP3·IMAP·SSH를 다시 재생했다. 중앙 장면의 장치, 이동 카드, 숫자만 보면서 출발 전과 도착 후를 대조했다. 기본 화면은 Chromium 1440×900이며 작은 화면은 390×844의 터치 에뮬레이션으로 확인했다. [수정 후 실제 장면 여섯 개](scene-comparison.jpg)

| 탐색기 | 다시 보는 방법 | 그림에서 확인한 변화 |
| --- | --- | --- |
| CPU | FCFS, 8ms에서 1ms 다음 | P1이 SSD에서 준비 큐로 이동하는 동안 P2가 ‘입출력 1ms 남음’으로 남아 있다. 빈 슬롯에는 글자가 없고 10ms에 P2까지 떠나면 ‘입출력 요청 없음’이 나타난다. |
| 트랜잭션 | 일반 SELECT, 9번 다음 사건. 같은 구간을 ‘읽기부터 잠금’으로 비교 | 일반 읽기에서는 T2 장치가 계산한 9가 ‘재고 ← 9’ 카드로 이동한다. DB 도착 전에는 확정 9만 있고, 도착 후에는 확정 9와 미확정 9(10 − 1)가 나란히 표시된다. 커밋하면 이번 주문의 실제 차감은 0개다. 잠금 읽기에서는 T2가 9를 읽어 8을 쓰고 실제 차감 1개가 표시된다. |
| 프로토콜 | FTP 3~6단계, PASV 응답에서 전송 종료까지 | 서버에 제어 21과 데이터 50069가 따로 붙는다. RETR과 응답은 21, 파일 조각과 FIN은 50069를 사용한다. 226이 돌아올 때 제어는 ‘연결됨’, 데이터는 ‘종료’다. QUIT에 대한 221 응답 뒤 제어 연결도 종료된다. |
| 메모리 | LRU, 7번째 접근 뒤 다음 E 요청. FIFO는 첫 교체를 예측한 뒤 확인 | LRU 선택 순간 A·D·B의 마지막 사용 시각 6·5·7이 강조되고, D의 5가 반전된다. FIFO에서는 같은 자리에 있는 프레임에서 적재 시각을 비교한다. 퀴즈 답변 전에는 강조가 없다. 모션 감소나 직접 이동으로 중간 선택을 생략하면 끝난 결정의 근거를 완료 표시에서 읽을 수 있다. |
| 디스크 | SSTF, 헤드 67에서 세 번째 요청. FCFS는 마지막 65→67 | 큐와 플래터의 같은 두 후보에 실선 ‘37번 · 30칸’과 점선 ‘98번 · 31칸’이 표시된다. 헤드가 움직이면 선택한 트랙에 방향과 거리가 남는다. 모바일에서 팔이 짧게 움직이는 65→67도 ‘안쪽 2칸’으로 읽히고 최종 누적은 640칸이다. |
| Git | C1 기록 뒤 5번 main 전환 | C0에서 작업 파일과 스테이징으로 경로가 갈라진다. 이동 중에는 두 곳 모두 기존 C1의 제목을 유지하고 도착하면 같은 줄이 C0의 제목으로 바뀌며 각각 ‘C0 복원’이 붙는다. HEAD는 main으로 옮겨지고 feature/title은 C1에 남는다. |

## 메일함과 터미널에 남는 결과

- **POP3** — 노트북에 메일 1의 사본이 생기고, DELE 1을 서버가 받으면 서버 쪽에만 ‘삭제 예정’이 붙는다. QUIT을 받으면 서버에는 메일 2만 남고 노트북에는 메일 1 사본이 남는다.
- **IMAP** — 읽은 메일 2가 서버와 노트북 양쪽에 남는다. 새 메일 3이 도착한 순간은 서버 3통·노트북 2통이다. 서버 알림이 노트북에 도착해야 노트북도 3통과 새 메일 +1을 표시한다.
- **SSH** — 노트북 터미널은 각 에코가 돌아올 때 p → pw → pwd로 갱신된다. 출력 패킷이 도착한 다음 줄에 /home/alice와 새 프롬프트가 남는다.

## 재생과 상태 확인

- CPU와 트랜잭션은 일반 재생으로 확인하고, 트랜잭션의 쓰기 요청 도중 일시정지·회전·재개·되감기를 확인했다. 미확정 값은 쓰기 요청 도착 뒤에만 표시됐다.
- 메모리와 디스크는 결정 중에 화면 너비를 바꾸어도 선택 기준·후보·경과율이 유지됐다. 직접 단계 이동과 모션 감소 설정에서도 완료한 선택을 확인했다.
- Git은 모바일 세로에서 복원 중 멈추고 가로로 회전한 뒤 이어서 재생했다. 일시정지 중 기록은 4건이었고, 재개 후 두 제목이 복원됐다. 뒤로 이동하면 복원 표식이 지워지고 5번을 다시 선택하면 같은 두 줄에 나타났다.
- 여섯 앱의 자동 검사 총 82개가 통과했다. 프로토콜 26개, CPU 17개, 트랜잭션 18개, 메모리 11개, 디스크 3개, Git 7개다.
